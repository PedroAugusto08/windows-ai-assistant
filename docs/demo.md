1. Show the Central and floating assistant. Briefly identify the stack and trust boundary: model interpretation, local authorization, SQLite receipts.
2. Create a manual synthetic task, `Revisar dataset sintético Atlas`, and show it in the task panel. Demonstrate that manual controls work without the provider.

Otherwise omit this step; do not relabel a fixture as a live call.
4. With live evaluation separately authorized, request a task such as `Crie a tarefa Preparar demo Atlas`. Show the review before approving, then the confirmed local result. Use the actual UI behavior rather than promising an exact generated sentence.
5. In Executor, select only a synthetic pending task, review the plan, consent and start. Show the receipt. State that interruption requires renewed review; no automatic restart is promised.
6. Close with limits: Portuguese interface, no voice, no arbitrary shell, no source-reading research, memory experiments excluded.

Keep raw recordings private until reviewed for task names, notifications, desktop identity and account data. No recording, screenshot or provider call is produced by the preparation tooling.
